# Week 1 Case Study

## Title
Portfolio Management System – Project Initialization

## Background

A software company wants to develop a Portfolio Management System for managing user portfolios. Before development begins, 
the team must prepare the development environment and create the initial project structure.

## Learning Objectives

- Understand Java platform (JDK, JRE, JVM)
- Install Eclipse IDE
- Configure Git and GitHub
- Create PortfolioProject

## Student Activity

- Install Java
- Create GitHub Repository
- Create Java Project
- Execute first Java program

## Expected Outcome

A working Java development environment with the PortfolioProject successfully created and uploaded to GitHub.

# Lab 3 – Collections Deep Dive using HashMap

## Aim

To implement Java Collections Framework using HashMap for efficient storage and retrieval of portfolio assets and compare lookup performance using System.nanoTime().

---

## Theory

HashMap stores data in key-value pairs and provides average O(1) time complexity for insertion, deletion, and lookup. Compared to ArrayList, HashMap improves performance for searching elements using unique keys.

---

## Concepts Used

- Java Collections Framework
- HashMap
- Key-Value Mapping
- CRUD Operations
- Performance Measurement using System.nanoTime()

---

## Files Modified

- Portfolio.java
- PortfolioService.java
- Main.java

---

## Algorithm

1. Replace ArrayList with HashMap.
2. Use Stock ID as the key.
3. Store Asset objects as values.
4. Implement Add, Search, Update, Delete using HashMap.
5. Calculate Portfolio Value.
6. Measure lookup time using System.nanoTime().

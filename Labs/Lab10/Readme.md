# Lab 10 – Stream API & Lambda Expressions

## Features Implemented

- Display Stocks using Stream API
- Highest Priced Stock
- Lowest Priced Stock
- Average Stock Price
- Total Stocks
- Total Quantity
- Portfolio Analytics Menu

## Stream API Methods Used

- stream()
- forEach()
- max()
- min()
- mapToDouble()
- mapToInt()
- average()
- sum()
- count()

## Outcome

Portfolio analytics implemented using Java Stream API and Lambda Expressions without using explicit iteration for the analytics logic.

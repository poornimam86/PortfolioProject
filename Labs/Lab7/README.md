# Week 07 – Lab 7: ExecutorService and CompletableFuture

## Aim
To improve application performance using ExecutorService and CompletableFuture.

## Theory
ExecutorService manages thread pools efficiently, while CompletableFuture enables asynchronous programming and parallel task execution.

## Concepts Used
- ExecutorService
- Thread Pool
- CompletableFuture
- Asynchronous Programming

## Files Modified
- PriceService.java
- PortfolioService.java
- Main.java

## Algorithm
1. Create a fixed thread pool.
2. Submit asynchronous tasks.
3. Wait using CompletableFuture.allOf().
4. Compare sequential and concurrent execution.
5. Shutdown ExecutorService.

## Expected Output
- Faster execution
- Reduced processing time
- Proper thread management

## Conclusion
Successfully implemented asynchronous processing using ExecutorService and CompletableFuture.
